## 📌 Descrição
Repositório criado para reunir exercícios desenvolvidos durante meus estudos de Python e lógica de programação.
Os exercícios têm como objetivo praticar conceitos fundamentais da linguagem, como variáveis, operadores, estruturas condicionais, estruturas de repetição, listas, strings, dicionários, funções e outros recursos da linguagem.


## 🎯 Objetivos
- Desenvolver lógica de programação;
- Praticar a sintaxe da linguagem Python;
- Trabalhar com entrada e saída de dados;
- Utilizar estruturas condicionais;
- Utilizar estruturas de repetição;
- Manipular strings;
- Trabalhar com listas e dicionários;
- Desenvolver funções;
- Resolver problemas utilizando algoritmos;
- Utilizar bibliotecas Matplotlib, NumPy, SciPy e Pandas.
